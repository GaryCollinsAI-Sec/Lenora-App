## About Lenora

Lenora is a faith-centered dating platform designed for adult members of The Church of Jesus Christ of Latter-day Saints (LDS) who are interested in building meaningful connections and pursuing serious relationships.

The platform emphasizes shared faith, personal values, compatibility, and genuine relationships.

**Disclaimer:** Lenora is an independent project and is not affiliated with, sponsored by, or endorsed by The Church of Jesus Christ of Latter-day Saints.

## Project Vision

The goal of Lenora is to provide a dating experience that goes beyond traditional profile-based matching.

By emphasizing shared beliefs, personal values, interests, and relationship intentions, Lenora aims to help individuals discover compatible partners and develop meaningful relationships.

## Core Features

- **Discover:** Explore member profiles and discover potential connections.
- **Likes:** Express interest in other members and manage incoming likes.
- **Matchmaker:** An AI-assisted matchmaking experience designed to help members discover compatible profiles based on shared interests, beliefs, and preferences.
- **Messages:** Communicate with matches and develop connections.
- **Profiles:** Create and manage personal profiles, interests, values, and relationship preferences.
- **Privacy and Safety:** Account management, privacy controls, member blocking, and safety-oriented features.

## System Architecture

Lenora is being developed as a responsive web application supporting desktop and mobile experiences.

The planned architecture separates frontend functionality, backend services, database infrastructure, and AI capabilities.

1. **Frontend Layer:** React, TypeScript, and HTML provide the user interface.
2. **Backend Layer:** Supabase provides authentication, application data services, and supporting infrastructure.
3. **Database Layer:** PostgreSQL manages relational application data.
4. **AI Layer:** Python and LangChain are planned to support intelligent matchmaking and AI-assisted interactions.
5. **Integration Layer:** Secure communication between application services and AI functionality.

## AI-Powered Matchmaker

The Matchmaker is intended to be one of Lenora's distinguishing features.

Through the planned integration of LangChain and large language models, the Matchmaker aims to provide:

- Compatibility-based profile discovery.
- Shared-interest and shared-value analysis.
- Personalized conversation starters.
- Icebreaker suggestions.
- Context-aware matchmaking assistance.
- Natural-language interactions.

AI-generated recommendations are intended to supplement individual preferences rather than independently determine relationship compatibility.

## Security and Privacy

Security is a fundamental development requirement for Lenora.

The project emphasizes a layered security approach, including:

- Secure authentication and session management.
- PostgreSQL Row Level Security (RLS).
- API security and input validation.
- Protection of sensitive user information.
- Privacy and visibility controls.
- Abuse prevention and member safety.
- Secure handling of application secrets.
- Monitoring and operational security.
- AI access controls and data protection.

Security considerations will be incorporated throughout development rather than treated as a final deployment task.

## Business Model

Lenora is planned around a freemium business model.

The initial objective is to provide meaningful core functionality while exploring optional premium features and potential microtransactions as the platform develops.

## Development Status

**Status: In Progress**

Lenora is currently under development.

Frontend functionality is being developed incrementally, with backend infrastructure, security implementation, and AI integration planned as part of the broader application architecture.

Features and architecture may evolve as development progresses.

## Project Goals

1. Build a welcoming faith-centered dating platform.
2. Encourage meaningful relationships through compatibility-focused matchmaking.
3. Provide an intuitive desktop and mobile experience.
4. Establish a secure and scalable backend architecture.
5. Integrate AI-assisted matchmaking using LangChain.
6. Develop sustainable monetization opportunities.
7. Prioritize user privacy, safety, and trust.
